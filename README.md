# نور هشتم — پروژه‌ی ری‌اکت (بدون CDN)

این پروژه با **Vite + React** ساخته شده: یک پروژه‌ی استاندارد و کامپوننت‌محور،
بدون هیچ اسکریپت CDN (نه React از CDN، نه Tailwind از CDN، نه حتی فونت‌ها از
Google Fonts). همه‌چیز موقع build داخل خود پروژه باندل می‌شود.

## راه‌اندازی

```bash
npm install
npm run dev
```

بعد از اجرای `npm run dev`، آدرسی مثل `http://localhost:5173` برایت باز می‌شود
و هر تغییری که در کد بدهی بلافاصله در مرورگر دیده می‌شود.

## ساخت نسخه‌ی نهایی (برای آپلود روی هاست)

```bash
npm run build
```

یک پوشه‌ی `dist` ساخته می‌شود؛ کل محتوای همین پوشه را روی هاست (هر هاست
استاتیکی: cPanel، Liara، Netlify، Vercel، GitHub Pages و...) آپلود کن.

برای پیش‌نمایش همین نسخه‌ی نهایی روی سیستم خودت، قبل از آپلود:

```bash
npm run preview
```

## ساختار پروژه

```
src/
  main.jsx          نقطه‌ی ورود؛ فونت‌ها و استایل سراسری را import می‌کند
  App.jsx            اتصال همه‌ی بخش‌ها و مدیریت state مودال‌ها
  index.css          رنگ‌ها، فونت‌ها، و تمام کلاس‌های سفارشی (دکمه، کارت، مودال و...)
  data/
    products.js       لیست محصولات، قیمت‌ها و توضیحات
    contact.js         شماره‌تماس‌ها، لینک باسلام، و مسیر لوگو
  components/         هر بخش سایت در یک فایل جدا
public/
  photo/               عکس‌های محصولات و لوگو را اینجا بگذار
```

## گذاشتن عکس‌ها (لوگو و محصولات)

هر فایلی را داخل `public/photo/` بگذاری، در کد با مسیر `/photo/نام-فایل`
صدا زده می‌شود:

- **لوگوی هدر**: فایل را با نام `logo-main.png` داخل `public/photo/` بگذار
  (یا اسم/پسوند دیگری استفاده کن و مقدار `LOGO_SRC` را در
  `src/data/contact.js` مطابقش کن). اگر فایل نباشد یا بارگذاری نشود، به‌طور
  خودکار متن «نور هشتم» جایگزینش می‌شود — سایت هیچ‌وقت خراب نمی‌شود.
- **عکس محصولات**: مسیر هر محصول در `src/data/products.js`، فیلد `image`.
  همین الان دو محصول («قاب نقره حرز و ادعیه» / «پک کامل») به
  `/photo/حرز-امام-جواد.jpg` و یکی به `/photo/ابی-دحانه.jpg` اشاره می‌کنند؛
  فقط کافی‌ست همین فایل‌ها را با همین نام داخل `public/photo/` بگذاری.

## ویرایش محتوا

- **محصولات، قیمت، توضیحات**: `src/data/products.js`
- **شماره‌تماس‌ها و لینک باسلام**: `src/data/contact.js`
- **متن‌های صفحه (هیرو، درباره‌ما، ساعات کاری)**: همان کامپوننت مربوطه در
  `src/components/` (مثلاً `Hero.jsx`, `About.jsx`, `Contact.jsx`)

## نکته درباره‌ی یکی از شماره‌ها

مقدار فعلی `tel` برای «شماره دوم» در `src/data/contact.js` این‌طور است:
`+9893389733748` — این ۱۳ رقم بعد از `+` دارد (یک `3` اضافه نسبت به حالت
عادی ایران که باید ۱۲ رقم باشد، مثل شماره‌ی اول). چون این داده‌ی خودت بود
دست‌نخورده نگه‌داشتمش، ولی بهتره یک بار چک کنی درست باشد وگرنه دکمه‌ی تماس
برای این شماره کار نمی‌کند.
